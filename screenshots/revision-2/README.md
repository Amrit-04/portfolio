# Visual Validation Archive — Revision 2 (Art-Direction Overhaul)

This directory contains the complete visual audit and high-resolution screenshot archive of the portfolio redesign revision 2.

## Creative Direction & Architectural Principles

- **Primary Visual Reference:** [Tiago Fragoso](https://tiagofragoso.com/) — Hand-drawn illustrated physical world, workshop facade, architectural exhibition walls, and hand-lettered signage.
- **Interactive Game Reference:** [Free Rider HD](https://www.freeriderhd.com/) — 2D Verlet bicycle physics, immediate dynamic launch ramp & ravine jump, background scenery lines, collectible golden stars, and a scoped in-browser track editor.
- **Engineering Integrity:** All 7 client-side browser demos (WASM ONNX GNN, LRCP Trace Waterfall, Kafka Replay, FIX 4.2 OMS, Merton Jump-Diffusion, Spatial A*, Workplace Safety Vision) run in real time with zero mock data fabrication.
