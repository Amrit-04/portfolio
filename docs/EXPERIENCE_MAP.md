# Reference adaptation experience map

Updated 2026-11-17; supersedes the rejected workshop navigation.

Arrival → brief ink splash (normal motion only) → framed project reel. On the first normal-motion phone visit a dismissible desktop recommendation appears. Reduced motion skips those holds and pauses the reel. The reel supports pause/play, next, fullscreen and opt-in synthesized sound.

Sticky [ABOUT] / [WORK] / [Links] → illustrated biography with correction note / six hand-drawn category boxes / bracketed contact and process illustration. The biography preserves the reference's composition instead of creating a new engineering introduction layout.

Work → category hover or touch preview → cream overlapping print wall. AI/ML contains neural query optimization and workplace safety; systems contains reliability and telemetry; finance contains Tradeflow and Moneyball; algorithms contains warehouse routing. A print → native project notebook → problem, contribution, decisions, source evidence, limitations and real demo → Escape closes notebook, restores its print and leaves wall open → second Escape closes wall and restores category focus.

Research → wide publication banner → workplace-safety record/authors/IEEE link → education/roles/résumé → source-supported skills and actual portfolio test tooling. Playground → bicycle illustration / honest homelab notes / existing experiments and clearly unfinished interests. Phone walls pan internally with a short cancellable hint and keyboard-scrollable region.

Links → canonical mailto / Socials dialog / Playground via +stuff. Socials provides GitHub, LinkedIn and email. The tilted process illustration, AY mark and long sign-off complete the page; the final character cycles short asides on click.

Playground's bicycle → separate `#/ride` → controls → nine-section physical trail → real star collection → checkpoint notebook (paused) → continue or full project notebook (still paused) → crash/ragdoll → checkpoint respawn → finish. Pause, mute and exit remain available. Browser back/forward restores the wall/ride route. Blur/visibility loss clears input and pauses.

Editor → independent draft → collision/scenery drawing, erase, undo/redo, clear → test a clone → return to draft → validated JSON import/export. Draft operations cannot mutate the authored trail. The game remains separate from the main portfolio's reference-led composition.
